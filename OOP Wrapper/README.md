# Employee Management System

## Features
- Create and manage Person, Employee, Manager, and Developer objects
- Store multiple employee records in a list
- Display details of Person, Employee, and Manager
- Encapsulation for employee ID and salary
- Inheritance and method overriding for specialized roles
- Exit option for program termination

## Program Flow
1. Display welcome message and main menu
2. User selects an option:
   - **Option 1:** Create a Person
   - **Option 2:** Create an Employee
   - **Option 3:** Create a Manager
   - **Option 4:** Show details of selected type
   - **Option 5:** Exit the program
3. Execute the selected functionality
4. Show results or confirmation messages
5. Continue until user chooses to exit

## Concepts Used
- Object-Oriented Programming (OOP)
- Classes and Objects
- Inheritance (`Person → Employee → Manager/Developer`)
- Encapsulation (private attributes with getters/setters)
- Method overriding (`display()` in subclasses)
- Lists for storing multiple records
- Loops (`while`) for menu-driven interface
- Conditional statements (`if`, `elif`, `else`) for option handling
- User input handling (`input()`)
