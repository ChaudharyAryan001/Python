# Personal Journal Manager

## Features
- Add new journal entries with automatic timestamp
- View all saved journal entries
- Search entries by keyword or date
- Delete all journal entries with confirmation
- Exit option for program termination

## Program Flow
1. Display welcome message and main menu
2. User selects an option:
   - **Option 1:** Add a new entry
   - **Option 2:** View all entries
   - **Option 3:** Search for an entry
   - **Option 4:** Delete all entries
   - **Option 5:** Exit the program
3. Execute the selected functionality
4. Show results or confirmation messages
5. Continue until user chooses to exit

## Concepts Used
- File handling (`open`, `read`, `write`, `remove`)
- Exception handling (`try`, `except`)
- String operations (splitting, joining, formatting)
- Lists for storing and processing entries
- Loops (`while`) for menu-driven interface
- Conditional statements (`if`, `elif`, `else`) for option handling
- User input handling (`input()`)
- Date and time handling (`datetime.now()`)
