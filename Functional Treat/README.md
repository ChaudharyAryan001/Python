# Data Analyzer

## Features
- Input dataset from user
- Display data summary (total elements, min, max, sum, average)
- Calculate factorial of a given number
- Filter dataset based on user-defined threshold
- Sort dataset in ascending or descending order
- Display dataset statistics (minimum, maximum, sum, average)
- Exit option for program termination

## Program Flow
1. Display welcome message and main menu
2. User selects an option:
   - **Option 1:** Input dataset
   - **Option 2:** Display data summary
   - **Option 3:** Calculate factorial
   - **Option 4:** Filter dataset
   - **Option 5:** Sort dataset
   - **Option 6:** Display dataset statistics
   - **Option 7:** Exit program
3. Execute the selected functionality
4. Show results or confirmation messages
5. Continue until user chooses to exit

## Concepts Used
- Lists for storing dataset
- Functions for modular design
- Recursion for factorial calculation
- Loops (`while`, `for`) for menu and data traversal
- Conditional statements (`if`, `elif`, `else`) for option handling
- Lambda functions with `filter()`
- String operations (splitting, joining, formatting)
- User input handling (`input()`)
