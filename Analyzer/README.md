# Data Analytics with NumPy

## Features
- Create arrays with user-defined rows and columns
- Perform mathematical operations (addition, subtraction, multiplication, division) on arrays
- Combine arrays vertically
- Search for values, sort arrays, and filter data based on conditions
- Compute statistical measures (sum, mean, median, standard deviation, variance)
- Exit option for program termination

## Program Flow
1. Display main menu
2. User selects an option:
   - **Option 1:** Create array
   - **Option 2:** Perform math operations
   - **Option 3:** Combine arrays
   - **Option 4:** Search, sort, or filter data
   - **Option 5:** Display statistics
   - **Option 6:** Exit program
3. Execute the selected functionality
4. Show results or confirmation messages
5. Continue until user chooses to exit

## Concepts Used
- NumPy arrays for data storage and manipulation
- Functions for modular design
- Loops (`while`) for menu-driven interface
- Conditional statements (`if`, `elif`, `else`) for option handling
- Array operations (`reshape`, `vstack`, `sum`, `mean`, `median`, `std`, `var`)
- Searching and filtering with `np.where` and boolean indexing
- User input handling (`input()`)
